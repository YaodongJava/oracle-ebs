# Oracle EBS 成本管理 8 周纸面实训

本课程以 `case-study.md` 为唯一贯穿案例，覆盖标准成本、BOM/Routing、库存/WIP、标准成本更新、期间关账和顾问交付。当前目录没有连接 Oracle EBS 实例；所有“结果”均为纸面推演，必须在目标实例用请求日志、分布、SLA 和 GL 报表复核。

## 使用规则

- 先读案例，再读当周任务；不要把纸面答案当作实例输出。
- 金额只在题目给定的成本基础下计算；账户、状态代码、并发程序参数以目标补丁级别为准。
- 每周交付物保留假设、公式、数量桥、价值桥、状态证据和未决问题。
