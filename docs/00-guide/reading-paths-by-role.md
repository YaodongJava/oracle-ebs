# 按角色阅读路径

## 适用范围与业务说明
为财务顾问、技术顾问、集成顾问、实施经理和运维人员定义由基础到专项的阅读顺序。

## 配置与实施要点
财务顾问先读企业结构和会计，再读模块和关账；技术顾问先读数据模型、标准入口和 ADOP；运维人员先读运行边界和排错。

## 核心对象与诊断范围
业务流程、配置工作簿、会计矩阵、接口契约、测试证据、运行手册。查询前在目标实例使用数据字典复核对象、列、状态值和访问权限；大表查询必须限制组织、账簿、日期或主键。

```sql
select owner, table_name, column_name, data_type
  from all_tab_columns
 where owner = upper(:p_owner)
   and table_name = upper(:p_table_name)
 order by column_id;
```

## 常见风险与排查
先执行 SQL 后理解业务状态；把只读诊断结论直接转化为生产修复。 排查时先确认业务状态、组织/账簿/期间和权限上下文，再逐层检查接口、会计和报表结果。
